# 无压球光照评分实验方案

日期为 2026-11-22。实验要检验的是，能否仅利用未接触曲面的逐灯功率微扰，预测该曲面附近的坡度灵敏度，并用它选择有利于局部形变重建的照明设置。

评分阶段使用曲面几何、灯位、无接触图像和相机噪声。独立验证阶段使用双轴倾角基准，直接测量真实法向变化造成的颜色变化。压球接触可用于后续触觉泛化评价，评分的计算和照明选择在查看这些结果之前完成。

当前方法是待验证的实验假设。功率微扰给出功率到 RGB 的导数，功率导数到坡度导数的换算采用局部朗伯、固定位置及稳定光路假设。相关文献及与既有方法的关系见 [文献调研](功率微扰换算坡度导数文献调研.md)。

## 1 要回答的三个问题

| 问题 | 实际操作 | 主要观察量 |
|---|---|---|
| 调光响应能否稳定测出 | 固定膜和相机，逐灯增加或减少少量光功率 | 功率导数的重复性、信噪比和步长稳定性 |
| 调光能否预测真实坡度响应 | 比较调光换算的导数与独立双轴倾斜测得的导数 | 导数的幅值、方向和空间误差 |
| 评分能否选出好的照明 | 对相同曲面比较多组照明，随后测独立倾角的重建误差 | 评分与误差的排序关系、最佳照明的实际改善 |

先完成一个中心位置上的小实验，再扩展空间位置和弯曲构型。只有前两项成立，第三项的评分才具备实测依据。

## 2 待验证的换算关系

在当前参考曲面上，记录材料点位置 \(X\)、几何法向 \(n_0\) 和正交切向基 \(E=[e_1,e_2]\)。沿用项目约定，参考光学法向为 \(n_{o,0}=-n_0\)，小坡度 \(\beta=(p,q)^T\) 对应

\[
n_o(\beta)=\frac{E\beta-n_0}{\sqrt{1+\|\beta\|^2}}.
\]

第一轮采用直线传播的近场点光源近似。第 \(j\) 个独立可控发光通道位于 \(\ell_j\)，令

\[
\omega_j=\frac{\ell_j-X}{\|\ell_j-X\|},\qquad
\mu_j=n_{o,0}^T\omega_j.
\]

\(\omega_j\) 应表示光到达膜面的实际入射方向。透明层折射明显时，需要根据真实光路计算这个方向，并将直线近似误差单独记录。发光面积较大的通道还需检查点光源近似。

保持其余灯为正常工作功率，将该灯光功率由 \(P_j\) 改为 \(P_j(1+\epsilon_j)\)，测量当前混合照明 RGB 的导数

\[
g_j=\left.\frac{\partial c}{\partial\epsilon_j}\right|_0\in\mathbb R^3.
\]

在位置、活动光源及可见性分支固定的朗伯近似下，待验证公式为

\[
\boxed{
\widehat D=\sum_{j\in\mathcal A}
g_j\frac{\omega_j^TE}{\mu_j}
}\qquad \widehat D\in\mathbb R^{3\times2}.
\]

\(\mathcal A\) 包含稳定照亮该点的有效光源。明确处于稳定无贡献分支的灯，其贡献为零。余弦接近零、可见性边界或几何不确定度足以改变分支的点，保留为单独的有效性记录。分母的可辨识性需要实际几何误差支持。

这个式子的物理含义是，法向变化造成的接收余弦相对变化，与同一灯的光功率比例变化在一阶上等效。灯位决定转换系数，\(g_j\) 给出相机在当前混光工作点的实测响应。近场距离、发射方向性和相机非线性已经影响 \(g_j\) 的数值，但它们随真实位移或光路变化的影响需要另外评价。[近场朗伯模型](https://arxiv.org/html/1707.01018)

## 3 设备和样件

| 设备或材料 | 用途 | 实施要点 |
|---|---|---|
| 现有相机和 LED 模块 | 复用实际 RGB 观测链和照明 | 曝光、增益、白平衡、图像处理设置可固定 |
| 独立可调光通道 | 对单颗灯作小幅功率变化 | 一个通道内的空间、光谱分布在微扰时应稳定 |
| 光电二极管或功率计 | 确认实际分数光功率变化 | 测量驱动值到相对光功率的关系，覆盖各基准功率 |
| 双轴倾角台及位置微调台 | 独立产生已知法向变化 | 两轴角度有独立读数，旋转中心可调到被测膜面 |
| 漫反射控制样片 | 检查硬件、符号和几何换算 | 使用稳定、近似朗伯的涂层 |
| 同工艺触觉膜样片 | 检验实际材料的角度响应 | 尽量复用实际胶层、涂层及保护层，记录制备批次 |
| 独立位置和姿态测量 | 检查转动中的位置漂移 | 可使用侧视相机、位移测量或经标定的机械读数 |

倾角台承载被测样件，相机和 LED 固定在独立基座。对一个被测位置，先将旋转中心调到该位置，再改变样件朝向。这个布置让参考点尽量保持原位置，法向发生已知变化。检查膜在夹具中的形状稳定性及机械回差；若膜相对夹具发生形变，真实膜面法向还需独立测量。

若先用独立验证夹具复用相机、灯和膜样片，应记录它与整机的光路差别。样片结论的适用范围由该夹具决定。完整胶层的折射、多次反射和整机遮挡会在后续整机评价中继续接受检验。

以下建议将角度读数不确定度控制到约 0.02°，并将参考点位置漂移控制到最近灯距的 0.2% 以内。这两项是实验起始设计值，应根据实际误差预算和预实验结果固定。

## 4 第一次实验的规模

最小版本采用一个固定参考构型、中心一个位置和六组照明。材料包括一片漫反射控制样片，以及三个同工艺触觉膜样片。单位置实验使用该点的最小信息特征值评分。完整感知面采集采用面积评分，并将独立验证扩展到中心和四个边缘位置、平面及两个实验可达的弯曲参考构型。

六组照明由当前基准、偏重弯曲方向两侧、偏重另一方向两侧，以及三组预先生成的可行功率配置组成。所有配置在硬件额定范围内，使用相同曝光和同一功率预算。若采用实测总辐射功率作为预算，保存逐通道功率；若采用电功率预算，同时报告该定义。

预先保存照明清单和随机采集顺序。后续增加照明数量时，使用新的留出设置检验排序。发表级排序研究可增加到十二组或更多设置。

| 参数 | 建议初值 | 如何确定最终值 |
|---|---|---|
| 功率微扰比例 | 2%、5%、10% | 独立预实验检查信噪比和导数收敛，再固定正式步长 |
| 基准噪声帧数 | 200 帧 | 检查噪声估计随帧数是否稳定 |
| 每个状态保留帧数 | 10 帧 | 保存单帧，计算 \(g_j\) 时使用均值 |
| 切换后初始丢弃帧数 | 5 帧 | 根据曝光同步、PWM 和驱动响应实测调整 |
| 每组微扰重复 | 3 个完整采集块 | 使用独立时段重复，检查漂移 |
| 直接倾角 | 两轴各 ±0.5°、±1°，另加零位 | 预实验检查步长依赖和几何误差 |
| 正式独立会话 | 3 次 | 每次重新定位并记录实际几何 |

这些数量和后面的判据是本方案的建议初值，正式实验前在独立预实验中固定。它们对应方法验证，工程验收精度另按应用需求确定。

## 5 操作步骤

### 5.1 检查功率控制和图像采集

1. 固定样件、灯和相机，预热到基准图像与光功率读数稳定。保存温度或稳定性记录。
2. 关闭自动曝光、自动增益、自动白平衡和随画面变化的自动增强。保存全部相机设置。
3. 对各发光通道测量驱动值到相对光功率的关系。微扰用实测光功率比例描述，记录上调与下调的实际幅度。
4. 检查单个通道调节时，其他通道的电流或光输出是否变化。供电耦合需要修正或计入不确定度。
5. 检查 PWM 与曝光的同步、滚动快门条纹及过曝区域。确定每次切换后的等待帧数。
6. 固定颜色域和采样方法。可沿用 inverse_sRGB 后取样，但整个采集、导数和噪声估计使用相同处理链。
7. 记录全灯关闭时的图像，检查外界漏光和非受控光源。若关灯状态仍出现随倾角变化的响应，将其作为需要补充的背景角度响应记录。

相机平滑非线性可以由当前工作点的微扰响应体现。量化、压缩、自动处理和局部饱和的影响由上述实测检查决定。先在一组固定设置中验证重复性，再进行照明比较。

### 5.2 采集无接触功率微扰

1. 将所有灯设为待评价的基准配置，采集 200 帧固定状态图像。
2. 在基准曲面上建立材料点位置、法向、逐点切向基和相机采样位置。保留几何来源及误差估计。
3. 按随机化顺序逐灯采集，每个采集块依次记录“基准、上调、下调、基准”。重复块交替交换上调和下调的先后顺序。
4. 每个状态等待稳定后保留 10 帧。每颗灯完成 3 个重复块，其余灯始终保持该配置的基准功率。
5. 用块前后的基准观测检查并估计漂移。保留原始图像和实际功率读数。
6. 在同一材料点计算

\[
g_j\approx
\frac{\overline c_j^+-\overline c_j^-}
{\epsilon_j^+-\epsilon_j^-}.
\]

对称微扰时分母为 \(2\epsilon\)。三种步长先用于预实验；正式采集采用预先固定的步长或预先声明的选步规则。选择依据为功率、信噪比与重复性。

若有 26 个独立通道，正式单步长采集每组照明约保留 \(200+26\times3\times4\times10=3320\) 帧。按每个状态再等待 5 帧计算，共约 4880 帧；60 fps 时纯采集约 81 秒，实际时间还包含通信与机械操作。历史仿真的 52 个光积分样本属于数值表示，实物采集数量由独立可控通道数决定。

### 5.3 换算导数并计算评分

1. 根据当前曲面与灯位计算各点的 \(\omega_j\)、\(\mu_j\) 和转换系数。
2. 由第 2 节公式得到 \(\widehat D\)。保存两个坡度方向各自对应的三通道导数。
3. 用未调光的固定状态帧，估计同一观测单位下的单帧 RGB 噪声协方差 \(\Sigma\)。若固定了材料邻域平均或滤波，也在相同处理后估计噪声。
4. 若在线使用当前图减参考图，按实际参考获取方式计入参考误差。独立的 \(M\) 帧均值参考在稳定条件下贡献约 \(\Sigma_0/M\)；共享误差或时间相关性需要单独统计。
5. 检查协方差估计的稳定性和条件数。量化或有限样本导致的零方差需要额外噪声测量支持；保存采用的噪声模型与数值处理。随后在局部固定协方差近似下计算

\[
\widehat F=\widehat D^T\Sigma^{-1}\widehat D.
\]

主评分延续最弱方向的思路，采用参考材料面积加权的 \(\lambda_{\min}(\widehat F)\) 第 5 百分位值。这个百分位是本方案对离散测量异常点的处理选择。同步报告全域最小值、面积分布和导数不可估计面积比例。

这个评分优先改善薄弱方向。平均角误差另采用匹配的预测量，在信息矩阵满秩、局部无偏和小坡度条件下计算

\[
R_A=\sqrt{\frac{\sum_i a_i\,\operatorname{tr}(\widehat F_i^{-1})}{\sum_i a_i}}.
\]

\(R_A\) 的单位近似为 rad。奇异区域的理想误差界无界，结合覆盖率单独报告。最弱方向评分对应最弱方向的不确定度，\(R_A\) 对应平均角误差，两个目标分别验证。

参考材料区域在比较前固定。过曝、弱响应和无效分支保留在覆盖率报告中。Fisher 信息的光学有效性、估计误差和覆盖率共同决定配置的评价。

评分采用实际在线单帧混合 RGB 的三个通道。逐灯微扰帧用于估计 \(D\)，基准噪声仍按单帧计算。重复块和独立会话给出评分的不确定度，防止微扰噪声把弱响应估计成较高的信息量。当前 \(F\) 采用 RGB 均值响应及局部固定协方差，光子噪声随状态改变时的完整统计信息需要另行建模。

### 5.4 用真实倾角取得独立参考导数

1. 保持灯光配置和曝光，调节样件的两个独立转轴。将被测材料点放在旋转中心，检查其位置漂移。
2. 记录零位和两轴各自的 ±0.5°、±1°，共 9 个姿态。每个姿态采集 20 帧，按随机顺序重复采集。
3. 从编码器或独立姿态测量得到几何法向 \(n_d\)，按冻结的零位参考基计算真实坡度

\[
\beta=-\frac{E^Tn_d}{n_0^Tn_d}.
\]

4. 对各姿态执行同材料点取样。转台轴名与坡度方向的对应通过几何计算确定。
5. 由真实 \(\beta\) 与颜色变化拟合 \(\Delta c\approx D_{\mathrm{ref}}\beta\)。比较不同角度步长的导数，确定局部线性范围。
6. 用 \(D_{\mathrm{ref}}\) 评价调光预测。首先报告面积加权相对导数误差

\[
e_D=
\sqrt{
\frac{\sum_i a_i\|\widehat D_i-D_{\mathrm{ref},i}\|_F^2}
{\sum_i a_i\|D_{\mathrm{ref},i}\|_F^2}
}.
\]

同时报告每一列的幅值比、夹角和弱响应区域的绝对误差。误差按空间位置、材料批次、照明和会话分组。

漫反射控制样片先检查符号、功率比例、灯位和相机测量。随后原样执行同工艺触觉膜验证，观察实际反射与胶层光路对换算的影响。

### 5.5 检验评分是否能预测重建误差

1. 完成六组照明的无接触评分并冻结排序，再采集新的倾角测试数据。
2. 采用未用于导数拟合的组合倾角。例如两轴转角取 \((0.3°,0.4°)\)、\((-0.3°,0.4°)\)、\((0.6°,-0.2°)\) 及其符号对称姿态。真实坡度仍由实际姿态计算。
3. 各设置采用相同形式的局部估计器，其参数来自独立倾角标定得到的 \(D_{\mathrm{ref}}\)。它构成一个接近局部最优解码的独立性能基准。
4. 对测试中的每一帧单独估计坡度和法向，统计角度 RMSE、P95、偏差和重复测量协方差。
5. 将同一小倾角下多次单帧估计的坡度协方差最大特征值，与 \(1/\lambda_{\min}(\widehat F)\) 比较。单位置评价最弱方向的方差，完整曲面比较其面积分布及第 95 百分位值。另将 \(R_A\) 与平均法向角 RMSE 对照。分别报告匹配目标的排序相关性、所选配置与基准的误差差值，以及误差椭圆方向。
6. 另用 \(\widehat D\) 解码，报告换算导数作为实际重建器时的附加偏差。

独立倾角基准提供真实法向变化，避免仅由 \(\widehat D\) 解码噪声再回算其代数协方差形成自验证。Fisher 信息对应模型正确、局部无偏估计的精度下界；系统偏差和有限角度非线性由实际误差报告。

统计重采样按独立会话、样片和位置进行，时间重复帧用于估计重复性。六组配置适合初步排序研究，更多留出配置用于评估排序结论的稳定性。

## 6 结果怎样判断

下表为预实验后可固定的初始判据。正式判断同时保留连续误差和置信区间。

| 观察量 | 建议起始判据 | 结果对应的含义 |
|---|---|---|
| 功率导数的重复性和步长稳定性 | 主要有效区域相对差约 10% 以内 | 调光响应具备可重复的局部导数 |
| 同工艺膜上的导数误差 | \(e_D\) 约 10% 以内，并检查弱列误差 | 功率到坡度的换算具有定量依据 |
| 有效覆盖 | 固定区域约 95% 可获得可信导数 | 评分覆盖大部分所需感知面 |
| 照明排序 | 最弱方向评分与负实测最弱方向不确定度的 Spearman 相关约 0.7 以上，报告区间；平均角误差另与 \(R_A\) 比较 | 评分对相应目标具有选择照明的初步能力 |
| 选优收益 | 根据预先指定的最弱方向或平均角误差目标，所选配置相对基准的独立测试误差降低，配对区间支持改善 | 评分可用于实际选择 |

如果控制样片上的换算误差较大，依次检查功率比例、符号、曝光同步、几何和材料点配对。如果控制样片成立而触觉膜偏差明显，检查非朗伯反射、折射、间接光及膜的空间非均匀性。如果导数吻合而照明排序较弱，检查噪声模型、评分汇总方式、覆盖率、有限倾角偏差和背景误差。

每一种失败都对应待检验的假设，报告具体条件下的有效范围。

## 7 向完整触觉面扩展

完整感知面继续只用无接触微扰计算评分。先测试平面，再测试两个固定弯曲构型，灯位和材料坐标按各构型更新。多位置的独立倾角验证需要能在对应位置设置旋转中心的参考样件或验证夹具，并保留其光路适用范围。

接触后的位移、遮挡变化与大坡度超出了固定点微分的定义。后续真实触觉验证可在评分冻结后，使用独立形貌真值评价有限压入。若采用已知球、斜面或其他物体，记录物体、位姿与标注误差，分别报告坡度、法向和位移。该验证回答评分对真实触觉任务的预测范围。

整体弯曲时位置、灯位和法向会共同改变，几何估计也可能受接触影响。这个评分首先评价给定参考构型的局部光学感知能力，完整链路的背景预测、材料配对和高度积分另有误差来源。

## 8 需要保存的记录

| 内容 | 最少记录项 |
|---|---|
| 设备状态 | 相机型号、全部成像设置、帧率、时间戳、通道定义、温度或稳定性记录 |
| 照明 | 配置编号、各灯基准功率或驱动值、微扰实际比例、功率标定关系和预算定义 |
| 几何 | 构型编号、材料身份、位置 mm、\(n_0\)、\(E\)、灯位 mm、倾角读数及不确定度 |
| 原始观测 | 基准、上调、下调和倾角图像，切换与稳定标记，样片及会话编号 |
| 分析结果 | \(g_j\)、\(\widehat D\)、\(D_{\mathrm{ref}}\)、单帧 \(\Sigma\)、\(F\)、覆盖标记、评分及其区间 |
| 独立测试 | 冻结的照明排序、真实与估计法向、角误差、重复测量协方差、配对误差差值 |

最终至少形成导数幅值与方向对照图、空间信息量与有效覆盖图、最弱方向评分对实测不确定度的散点图、\(R_A\) 对独立角误差的散点图，以及跨会话重复性表。结论写明材料、构型、照明预算和有效倾角范围。
