# 面向 LUT 补偿的光场模型反思

归档状态（2026-11-06）：本文讨论的 `physical_model/`、`sim2real_trial/` 两条光场路线已暂时废弃。下文的方案与实验建议仅作历史记录；旧代码目录仅在本地保留，源码链接不属于当前仓库的有效开发入口。

## 目标与结论

**我们不需要构建准确的模型，我们只需要这个模型能够预测弯曲后色差与法向量的关系。** 更具体地说：在原 LUT、参考图、颜色处理和深度 GN3 规则不变的条件下，模型应帮助从实测色差恢复当前曲面的局部法向，并改善最终重建。LED 的真实位置、材料参数、绝对辐射度和渲染外观不是必须单独求准的目标。

**简单优先，按收益率取舍：细微的效果变差可以容忍，简单模型比一点点结果改进更重要，只有结果明显退化才阻止简化。** 在实际任务容许的误差范围内，优先减少标定与运行成本、参数自由度、维护复杂度和不稳定性；不为很小的精度优势默认增加传播机制。

目前没有证据表明新增的完整折射、镜面和多次反射传播，对这一目标值得付出其计算成本。应当以使用整体重建曲面、可直接服务现有 GN3 的简洁响应模型为优先基线；更复杂的传播只在相同数据上的法向与补偿对照证明有收益时保留。现有实验也不足以证明光学传播的任何部分必然无用。

神经网络可以用于**离线学习实测色差—法向关系，辅助拟合现有响应模型参数**。推荐先建立不用网络的任务导向基线，再做网络辅助的对照；网络不进入运行时，不修改原 LUT、深度 GN3 求解、色差定义或重建链路。只有离线辨识出的、现有解析模型配置确实支持的参数可作为候选输入。实际补偿效果仍需独立实验验证。

## 1. 现有传播实验能说明什么

下列实验均来自[历史实测辨识记录](../sim2real_trial/docs/model_identification_process.md)，除特别注明外单位为 8 位相机码值，具体口径以各实验记录为准。这些历史对照采用平板传播和线形光源，不是 059 的曲面传播与方形光源。

| 对照 | 已观察到的结果 | 可得结论与边界 |
|---|---|---|
| 折射率 1.5 → 1.4 | 014 的 M2 几何固定时，空间/第二周期 RMSE 从 2.718/2.329 降至 2.676/2.289；混色留出从 2.123 升至 2.134 | 本批静态照明数据收益小且不一致。只重拟了强度，没有联合重拟几何；不能据此得出折射完全无效，也不能将 1.4 当作测得材料值 |
| 折射率 1.5 → 1.6 | 空间/第二周期变为 2.852/2.426 | 在该固定几何和所测范围内更差，不证明其他几何和任务下的结论 |
| 按光色调镜面保留率 | 九芯片实验的空间噪声归一化误差 4.230 → 3.960，第二周期混色 6.137 → 6.110 | 留出收益有限；该协议与全 26 灯实验不同，不能把数值直接横比，也不能认作材料标定 |
| 共同发射指数 0 → 1 → 2 | 固定 050 几何下空间/第二周期依次为 2.300/2.102、2.666/2.419、3.188/2.838 | 增大所试共同指数没有改善；不能推出真实发射指数恰为 0，或所有灯的角分布都不重要 |
| 入口折射与漫反射反馈对照 | 007 在固定名义 2 mm 灯位下，空间/第二周期 RMSE 从 0.03290/0.02206 降至 0.01992/0.01591，数值处于 0–1 的有效响应域 | 这是传播反馈改善静态预测的反例，不能说传播项从来没有作用；但该实验仍未通过预测门槛，也未评估接触法向或 LUT 补偿 |

这些实验大多改变的是**已含某些传播机制的模型中的参数值**，不是在相同标定条件下逐项关闭折射、反射或全局反馈的消融；测量的也主要是无接触表面的照明增量，而非压入时的法向响应。参数还会与有效强度、几何、颜色响应相互补偿。因而合理判断是：**现有证据没有证明这些扩展值得继续增加复杂度**，而不是已经证明它们对法向补偿完全没有影响。

新增复杂传播确有成本：059 曲面模型需要构建闭合网格、追踪射线与反馈，并在灯位变化时重新追踪。一次 26 灯名义源列的 native BVH 核验耗时约 23.7 秒；这只是一次源列计算，不是完整拟合或实时耗时。256 与 512 个源方向的局部亮区形状还相差约 2.32%（已消除单一亮度倍率），可能干扰小幅参数变化的判断。简洁解析模型与该后端在**相同输入、硬件、精度和任务**上的完整耗时对照尚未完成。

## 2. 当前链路距离目标还差什么

1. **059 的数据不覆盖接触法向。**它辨识的是固定工作光谱附近的逐灯亮度变化；其留出误差下降，不等于接触时色差对坡度的导数正确，更不等于 LUT 补偿后法向更准。
2. **当前曲面射线后端还不是形变前向模型。**[curved_transport.py](../sim2real_trial/utils/curved_transport.py) 冻结整体曲面网格及其传播；同一观测点上的 `optical_normals` 主要用于一致性检查，并不作为连续局部法向来更新入射和反射响应。局部形变需要新的曲面网格和传播计算。它不能直接替代 GN3 所需的逐点色差及坡度/深度 Jacobian。
3. **现有深度 GN3 使用另一套解析响应。**[depth.py](../physical_model/compensation_utils/depth.py) 计算每点的预测色差、2 列坡度 Jacobian 和 1 列深度 Jacobian，再按原规则进行三轮求解；冻结平面 LUT 提供坡度初值或先验。059 的灯光系数也不能未经颜色域、光源编号与参数约定核对，就直接当作该解析模型配置。
4. **真实链路仍需实现和验证。**当前 GN3 已在理想曲面仿真实验中运行，尚未接入 `reconstruction/recon.py`。仿真实验通常减去同曲率无接触背景，而真实流程可能使用固定参考图；两种色差基准必须按实际链路明确对应，不能默认为同一个背景。固定参考图与当前重建基面的处理见[原计划的实物 GN3 约定](optical_model_calibration_plan.md#28-从辨识模型接入实物-lut-与-gn3)。

对模型来说，关键不只是参考图 RGB，还包括在实际接触范围内色差随法向、位置及深度变化的规律，以及它们经过现有 GN3 后能否区分。即使参考图拟合完全一致，两个模型也可能给出不同的法向导数。三个颜色通道也不保证两个坡度和一个深度在每点都可辨识。

## 3. 怎样公平判断简化是否足够

后续实验建议按以下顺序进行；这些是待实施方案，不是已经获得的结果。

1. **固定任务与输入。**使用相同的整体重建曲面、材料点、参考图、原 LUT、相机颜色域、工作灯态和留出划分。保留空间块、完整接触姿态和曲率/采集批次留出；不在同一幅压球图的相邻像素中随机拆训练和测试。历史上反复查看过的第二周期不作为全新盲测。
2. **比较直接相关的基线。**至少比较直接查原 LUT、原 LUT 加现有深度 GN3 的简洁解析响应。仅当扩展模型能对相同候选坡度/深度提供可靠的色差和 Jacobian 时，才把它加入同一 GN3 对照；不能把冻结的 059 参考光场直接当成已有形变响应。模型增删机制时应在各自允许范围内重新标定，记录自由度和约束，避免只比较一次固定参数扫描。
3. **先看任务指标。**对独立接触样本统计法向角误差（中位、RMS、95 分位）、坡度误差、失败/边界/秩亏比例，以及最终重建的高度或形状误差；深度必须有独立可核验标签才评分。按曲率、位置、法向范围和接触深度分组，所有方法在共同有效点上比较，同时报告各自丢失的点。提前确定目标容差和相对改善要求，保留重复采集噪声及整姿态统计的不确定度。
4. **再解释色差与导数。**比较无接触整体弯曲色差、接触色差以及可观测范围内的坡度灵敏度；有可靠受控深度变化时再检查深度灵敏度。结合 GN3 的缩放后 Jacobian、条件数、弱深度与求解失败诊断，不以单一 RGB RMSE 代替法向验证。
5. **记录计算代价。**在同一设备和相同数据量上分别记录标定耗时、模型准备时间、单帧/逐点补偿耗时和内存，并检查数值设置是否收敛。若复杂模型未能在独立任务指标上稳定超过简单模型、却增加显著成本，就选简单模型。

保持整体曲面几何与简化传播并不矛盾：整体重建提供当前材料点位置、参考法向与切基；需要比较的是**光度响应的复杂度**，而不是把真实曲面重新当作平面。

## 4. 神经网络可以放在哪里

### 优先方案：网络仅作离线辅助标定

将网络作为一个独立的实测响应学习器，在离线阶段拟合有几何标签的接触数据。它可输入材料位置、整体基面状态、局部坡度和有可靠标签时的深度，输出与现有 LUT/GN3 同一颜色域、同一参考图约定的有符号 RGB 色差。零接触状态、参考色差及位置/法向变化要分别定义；不能用相机码值恒等近似冒充已经标定的线性 RGB。

网络是用于探索数据规律和生成候选监督的**教师模型**，不是运行时重建器。先以训练接触数据直接拟合现有解析响应允许的参数，再可比较加入网络预测或其局部灵敏度作为辅助约束是否改善独立姿态；网络本身也可能过拟合，它的导数不是测量真值。训练好后只导出已有 `physical_model` 配置格式可以表达的参数，再调用原 `build_response_field` 和原深度 GN3；不能把任意逐点 RGB 矩阵、059 的有符号系数或网络输出假装成现有配置支持的物理灯珠功率。

必须同时保留“不用网络、直接用同一批接触数据拟合参数”的对照。如果现有解析参数族无法表达老师学到的响应，或改变参数后实际 GN3 没有提高留出法向精度，就记录其表达能力不足，不强行输出看似精确的参数。网络可以辅助搜索，却不能从没有形变观测的数据中凭空恢复真实法向响应。

训练数据需要包含多个实际整体弯曲状态及位置、深度、法向范围内的接触，并保证每条样本的 RGB、对应材料点、当前参考面与标签对齐。压球可提供候选几何监督，但只有球的半径、姿态、实际贴合和对应关系经过核验时，才能使用球面法向；整体 marker 曲面的法向不是接触局部真值，原 LUT 的输出也不能当作验证它自身的真值。如果只有法向、没有可靠深度，应把深度视为未知量并如实报告，不能声称深度已验证。现有 059 无接触数据不足以单独训练和验证这项能力，历史压球数据的适用性也须先核对。

可把网络学到的预测与对应的局部响应斜率用于辅助约束，但应先用有控制的配对接触或可信几何标签验证：相同材料点、整体基面和参考条件下改变法向；若深度同时变化，必须显式控制或联合建模，不能把差值直接当纯法向导数。验证时重点仍是运行**未修改的**原 LUT 和 GN3 后得到的真实法向误差。

### 补充方案：直接针对补偿效果拟合现有参数

无需先引入网络，也可将可配置的等效光源/颜色参数作为外层变量，使用实测球压样本的色差误差与原 GN3 输出的法向误差来选择参数。外层可使用合适的数值搜索；若采用可微副本或替代模型求梯度，应先核验其前向、活动分支、三轮更新和输出与现有 GN3 一致，再用原实现复核所有候选。这改变的是**离线参数标定目标**，不改变实际的 LUT 或求解流程。高维参数和光度尺度歧义要靠约束、留出和多初值检查控制。

### 不纳入当前方案的接法

- 让网络直接从 RGB 输出法向，或者替代原 LUT：会改变现有重建/补偿方法，不符合本次约束。
- 让网络在 GN3 中直接输出残差、响应矩阵或 Jacobian：概念上可用于更一般的前向模型，但现有实现中的响应和导数与解析光源耦合，这需要修改前向及求导代码，不能称为当前 GN3 实现原样不变；本阶段不采用。
- 让网络在线修改输入色差、背景或 LUT 表项：会改变原方法的输入或经验映射，本阶段也不采用。

相关研究中，[NLiPsCalib 项目](https://nlipscalib.github.io/)使用近场光度立体获取接触几何并训练网络进行法向预测；[Kaya 等的神经逆渲染](https://openaccess.thecvf.com/content/CVPR2021/papers/Kaya_Uncalibrated_Neural_Inverse_Rendering_for_Photometric_Stereo_of_General_Surfaces_CVPR_2021_paper.pdf)展示了以网络表达反射和光照的可能性。这些工作说明学习有效响应是可研究的方向，并未证明本传感器无需独立接触标签，也不是本项目保持现有 LUT/GN3 不变的现成实现。

## 5. 建议优先级

1. 冻结原 LUT 与补偿规则，确认真实色差参考和颜色域，整理可用的独立接触几何标签。
2. 用整体重建曲面和简洁解析响应建立任务基线，在留出曲率与完整接触姿态上评估原 LUT 与原 GN3。
3. 用同样的接触数据先直接标定现有参数，再比较网络离线辅助标定；模型只作为配置候选，原 LUT 与 GN3 代码不变。
4. 只有任务指标显示简单模型存在可复现的结构误差，再逐项测试折射、反射或更灵活响应是否值得其复杂度；每次保留对应的无该机制基线与计算成本。

目前这些是分析和待验证方案，不代表已经获得可靠的接触法向数据、完成真实补偿接入，或证明神经网络一定有收益。
