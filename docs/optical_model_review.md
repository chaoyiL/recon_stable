# 无外部标定物的视触觉传感器光学辨识：文献综述与研究交接

归档状态（2026-11-06）：关联的 `physical_model/`、`sim2real_trial/` 光场路线已暂时废弃。本文保留为历史文献整理，不作为当前实施任务；旧代码目录仅在本地保留。

整理日期：2026-11-03。用途：交接给 workspace agent，作为后续理论分析、数据采集设计与原型实现的阅读入口。

本文整合本次对话中的两轮文献检索，来源包括用户 Zotero 的 `Tactile Sensor 1`、`Tactile Sensor 2` 及公开论文、作者机构页面和代码仓库。文献事实、根据文献作出的推断、针对本项目的候选方案分别标明。本文没有新增实物采集、渲染、训练或参数辨识实验。

## 1. 用户已经确认的任务与条件

任务目标：不添加平面反射镜、标定球、白板、marker 等外部标定条件，仅利用传感器的无接触图像和可控照明，辨识能够描述系统光照的参数，重点关注逐 LED 的位置、发射朝向及强度。

用户已确认：

- 可以逐 LED 独立调光，不仅是整条灯带调光。
- 无接触表面的三维形状、相机参数大致已知；其误差范围尚未给定。
- 希望找到“最小、又充分”的参数集合，并据实际图像反推这些参数。

当前不应自行增加的条件：

- 不默认允许压球或使用其他接触形状标签进行本项光学辨识。
- 不默认可以改变无接触表面的整体构型，或能够无 marker 精确测出多个构型。多构型采集只能作为有条件的后续选项。
- 不默认相机内参已知就等于相机辐射响应、曝光尺度、白平衡和暗角已经精确标定。
- 不默认胶膜为理想朗伯体，也不默认透明层折射、扩散和互反射可忽略。

本任务可以为本目录原有的“平面标定迁移到弯曲构型”提供光学参数基础，但本项辨识是否可行、辨识结果能否预测局部接触响应和整体弯曲响应，仍需分别验证。项目背景与符号约束见 [AGENTS.md](../AGENTS.md)、[既有相关研究综述](literature_review.md)和[候选迁移方法](plane_to_tangent_lut_calibration_transfer.md)。

## 2. 文献检索得到的主要判断

1. **最贴近本任务的新入口是 Coupry 等的 SSVM 2025 工作 [R1]。**作者机构摘要明确提出从粗几何估计逐光源位置、强度、朝向和各向异性因子，并有作者代码。其对固定平面和具体反射模型的退化处理，本轮尚未取得全文核对。
2. **视触觉领域已有无接触图像拟合光学参数的直接先例 [R2]。**但它识别的是按颜色归并的等效光源及反射系数，不能视为逐物理灯珠全参数辨识已经解决。
3. **逐灯强度估计、逐灯位置估计和发射分布估计是不同子问题。**PneuGelSight [R7] 主要提供已知几何下的有效强度估计先例；Guo 等 [R5] 的 RID 自标定也以光源位置已知为前提。
4. **“自标定”不代表没有先验或对所有场景唯一可解。**相关方法依赖粗几何、材料模型、光源模型、不同姿态或其他约束，必须逐篇检查输入。
5. **不应预设存在适用于所有实际传感器的固定最小参数数目。**应该在物理假设下定义模型层级，再判断现有采集条件能否区分参数，以及这些参数是否足以预测后续任务所需的响应。
6. **固定几何上反复改变同一颗 LED 的亮度，通常不能替代几何或角度多样性。**其作用首先是测量响应、检查线性和提高信噪比；不能据帧数增加直接宣称全参数可辨识。

上述判断不构成“本任务不可能”或“已有论文完整解决本任务”的结论，也不构成首创性证明。

### 3.1 R1：优先补读的最相关工作

作者机构摘要明确列出逐光源四类参数：position、intensity、orientation、anisotropy factor，并说明以粗几何进行 graduated optimisation，再用于近场光度立体。粗几何可由 SfM 等获得；对本项目而言，已有参考表面模型可作为候选几何输入，但其误差与论文输入条件是否相容仍待核对。

阅读与实现状态：

- 已核对作者机构摘要和 `BenjaminCoupry/LED-getter` 仓库入口。
- 曾查看入口脚本，尚未审阅完整辨识模块、固定源码版本或运行作者代码。
- HAL 全文与机构 PDF 在本轮访问受限，未完成论文方法与实验章节核对。
- 下一步应优先核对：反照率如何建模、参数释放顺序、初始化、尺度固定、几何误差、可见性，以及是否分析平面或小视场退化。

### 3.2 R2：最适合建立无接触拟合基线

第 2.1.1 节、式 (6) 以无接触平面上的图像残差为目标，优化各颜色的等效位置 $S^j$ 和系数 $\rho^j$；另保存残差补偿与初始光照矩阵，供在线重建使用。

论文第 2.1 节明确解释：一个颜色的等效光源位置一般不同于该颜色任一实际 LED 的物理坐标。因此，这篇论文支持“无接触图像可用于模型拟合”，却不能证明“无接触图像能唯一找回每颗 LED 的真实位置”。其 $\rho^j$ 按反射系数处理，不能另行称为独立测得的灯珠物理功率。固定硬件上的等效点，也不能未经论证就按某个材料点搬运到弯曲构型。

### 3.3 R3：紧凑参数化与尺度关系的基础

第 2.1–2.2 节使用点位置、单位发射主轴、强度及余弦幂指数描述 LED。单色光源的常用模型共有 7 个自由度：位置 3、单位方向 2、强度 1、指数 1。但原文的发射指数可由厂商半强度角计算，并非所有量都在同一数据中自由辨识。

原标定利用多姿态镜面球定位，再用多姿态漫反射平面估计主轴和强度。光度强度系数包含相机参数及标定板反照率的共同尺度，支持本项目优先估计有效相对强度，而不是直接输出 W。

### 3.4 R5 与 R6：需要发射分布模型时再使用

R5 的局部球谐 RID 可作为余弦幂不足时的扩展；其局部拟合不保证未观测发射角上的外推。若同时开放任意 RID 与未知灯位，二者更容易相互补偿，应先检验可辨识性。

R6 展示空间亮度分布包含几何线索，但其多个平面相对姿态提供了额外约束。不能把论文中的多姿态输入替换成同一平面的强度缩放，然后沿用原结论。

### 3.5 R7：强度求解可单独成为一个阶段

第 5.1 节、式 (6)–(9) 将 24 个光源的距离与角度系数写入 $A\in\mathbb R^{n\times24}$，以线性化颜色 $b\in\mathbb R^{n\times3}$ 估计 $x\in\mathbb R^{24\times3}$，再作背景预测。可借鉴其“几何系数与强度分离”的思路。

原文写为 $x=A^{-1}b$。当 $n\ne24$ 时不应照抄成普通矩阵求逆，实现应使用适当的最小二乘、伪逆或正则化，并检查秩与条件数。论文中的强度含比例因子，不应直接解释为绝对辐射功率。
