# 压入深度差与法向夹角分析

输入 `recon` 或 `local-recon` 输出的局部重建 NPZ，计算各压痕的最大深度、两两深度差、球面拟合结果及球心到整体曲面的投影连线夹角。必须手动指定要分析的文件路径：

```bash
uv run python -m experiments.indentation_analysis \
  assets/reconstruction/pc/curve_3b_local_result.npz
```

默认在输入文件旁生成 `<输入文件名>_analysis/`。可手动指定其他输出目录、接触区数量、识别阈值和初始区域点数：

```bash
uv run python -m experiments.indentation_analysis /path/to/result.npz \
  --output-dir /path/to/analysis --count 3 --threshold-mm 0.2 --min-region-points 100
```

输入必须包含 `xyz_out`、`displacement`、`displacement_vectors`、`valid_mask`、`photometric_valid_mask`。XYZ 与位移单位为 mm；位移的负方向表示压入。整体接触曲面由 `xyz_out - displacement_vectors` 恢复，均使用相机 XYZ 坐标。只分析规则二维网格，不接受缺少这些字段的普通 PLY、PCD 或单纯 XYZ 点云。

程序以 0.2 mm 为默认识别阈值，用八邻域连通分量找出独立压痕，每个初始区域默认至少 100 个几何有效点。区域按峰值网格行、列排序编号。区域数量不符时直接报错，可调整 `--threshold-mm`、`--min-region-points` 或 `--count`；不会静默选择部分区域。最大深度取几何有效点的最小负位移，包括光度无效但有几何结果的点。扩大区域时，按网格行列到各峰值的距离分配区域，避免浅层接触区相互合并；这只是分区规则，不代表曲面物理弧长。

对每个压痕，从最深点开始向外围扩大球冠：最低深度从该压痕峰值的 95% 逐档下降到 10%，每档下降 5%。每档只使用光度有效的重建点，在三维空间最小化球面径向残差。首次连续三档满足以下条件时，取第三档作为结果：

- 直径跨度不超过三档均值的 2%，球心最大两两距离不超过 0.1 mm。
- 每档至少 100 个点，球面拟合 Jacobian 条件数均小于 100。

球心通过整体曲面网格的三次样条做最近点投影，连线方向由投影点指向球心。网格有无效区域时，投影只使用周围 4×4 点全部有效的局部插值；不支持的边界投影会被拒绝。有限种子搜索不保证任意折叠曲面的全局唯一最近点。

有三个或以上有效球心时，程序分别检查方向向量共面性和所有连线端点的最佳拟合平面，并给出投影至端点平面后的夹角。方向共面不等于空间直线共面；报告中的延长线最短距离属于无限直线，可能对应远离接触区的点，不代表实际短线段的距离。方向近乎平行时不报告这一距离。仅有两个可用方向时仍输出其三维夹角，但不定义共同平面。

输出目录包含 `analysis.json`、`depth_sweep.csv` 和 `analysis.png`；再次运行会覆盖同目录下这三个文件。JSON 记录峰值、球心、投影点、各对深度差与夹角以及共面指标；CSV 记录每档球径、残差和稳定选点；图片显示扫描曲线、接触区和 X-Z 投影。若某一区域无法稳定拟合或投影，程序仍保存最大深度和可计算的结果，对无法确定的角度标记为空并以状态码 1 退出。输入或接触区识别错误以状态码 2 退出。

稳定条件只表示首次出现的局部平台，不能保证继续扩大后仍稳定；应检查完整扫描曲线。球径和夹角由重建点推算，球面残差也不是实物测量的不确定度。
